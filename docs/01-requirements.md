# ERP 系统需求与模块清单

## 1. 项目定位

企业级 ERP 系统，采用模块化单体架构：Java 21 + Spring Boot 3（后端）、Vue 3 + JavaScript（前端）、MySQL 8（持久化）。目标是可运行、可验证的业务闭环，而非静态原型。

## 2. 角色定义

| 角色 | 说明 | 典型权限 |
| --- | --- | --- |
| 超级管理员 | 系统内置，不可删除 | 全部菜单与接口 |
| 销售经理 | 销售业务负责人 | 销售订单、报价、客户、发货、应收查看、销售报表 |
| 销售专员 | 销售执行 | 客户、销售订单（提交/查询） |
| 采购经理 | 采购业务负责人 | 采购订单、供应商、收货、应付查看、采购报表 |
| 采购专员 | 采购执行 | 采购申请、采购订单（提交/查询） |
| 仓库管理员 | 仓储执行 | 库存查询、出入库、调拨、盘点、库存冻结 |
| 财务专员 | 资金与往来 | 应收应付、收付款、核销、对账、财务报表 |
| 审批人 | 按角色/金额匹配的审批节点 | 审批通过/驳回 |

## 3. 功能模块清单

### 3.1 系统管理（system）

- 登录 / 退出 / 当前用户信息 / 修改密码
- 用户管理（新增、编辑、启停、重置密码、分配角色、所属部门）
- 角色管理（角色 CRUD、菜单权限分配、数据范围）
- 菜单与按钮权限管理（树形菜单、权限标识）
- 部门 / 组织管理（树形结构）
- 字典管理（字典类型、字典项）
- 系统参数配置（键值、分组）
- 单据编号规则（前缀 + 日期 + 流水号，数据库自增序列）
- 登录日志、操作日志（AOP 记录）、审计查询

### 3.2 基础资料（masterdata）

- 商品分类（树形）、商品/SKU（编码、规格、单位、税率、采购价、销售价、状态）
- 计量单位
- 客户档案（编码、等级、联系人、信用额度、状态）与联系人
- 供应商档案
- 仓库、库位
- 数据导入 / 导出（CSV/Excel）、编码唯一性校验

### 3.3 库存管理（inventory）

- 实时库存（按商品 + 仓库 + 批次汇总，含可用量 = 在库 - 预留 - 冻结）
- 库存流水（每次变动记录 biz_type、单据号、前后数量，可追溯）
- 其他入库 / 其他出库 / 仓库调拨 / 库存盘点（盘盈盘亏）
- 库存冻结 / 解冻、库存预留 / 释放
- 批次管理、有效期与临期预警
- 安全库存与补货建议
- 库存成本（移动加权平均）、库龄与周转率报表
- 并发安全：行锁 + 乐观锁，防止超卖与重复扣减

### 3.4 采购管理（purchase）

- 采购订单（明细、税率、折扣）→ 提交审批 → 审核通过
- 分批收货（收货单）→ 采购入库（自动生成库存流水 + 应付）
- 采购退货（红字入库）
- 供应商对账、采购价格与供应商绩效分析

### 3.5 销售管理（sales）

- 销售订单 → 提交审批 → 审核通过
- 发货通知 / 销售出库（批次可选，自动生成库存流水 + 应收）
- 部分发货、销售退货（红字出库）
- 客户对账、销售业绩与毛利分析

### 3.6 财务与结算（finance）

- 应收账款、应付账款（由出入库单据自动生成）
- 收款登记、付款登记、核销（支持一单多次、一次多单）
- 预收款 / 预付款
- 资金账户与账户余额
- 费用报销（提交审批 → 付款）
- 应收应付账龄分析、收支统计

### 3.7 审批工作流（workflow）

- 流程定义（业务类型、节点、审批人角色/用户、金额条件）
- 提交 → 多级审批 → 通过/驳回/撤回/转交/会签
- 审批历史与意见
- 审批结果回写业务单据状态（仅后端执行）

### 3.8 CRM（crm）

- 客户线索、商机、销售跟进记录、拜访计划
- 销售漏斗、客户分级标签、购买历史与贡献分析

### 3.9 报表与仪表盘（report）

- 销售额/采购额、库存金额、应收应付、逾期账款、订单完成率
- 商品销售排行、客户业绩排行、供应商绩效
- 销售/采购/库存趋势，自定义时间区间与多条件筛选
- 明细钻取、Excel/CSV 导出

## 4. 假设与默认值

1. 单公司、单时区（Asia/Shanghai）、人民币本位币；多币种仅保留字段级扩展点。
2. 生产制造（production）与人力资源（hr）为可选模块，本轮不交付，状态标记"未开始"。
3. 审批流采用"按业务类型 + 金额条件匹配审批链"的简化模型，不做图形化流程设计器。
4. 库存成本采用移动加权平均法。
5. 税率按明细行税率计算，金额统一 `BigDecimal`，精度 4 位小数、金额 2 位小数。
6. 重要单据禁止物理删除，提供作废/关闭/冲销。

## 5. 非功能需求

- 密码 BCrypt 存储；JWT 无状态认证；接口级 RBAC 校验 + 数据范围过滤。
- 关键写操作幂等（请求幂等键 / 单据状态机校验），事务边界在 Service 层。
- 统一响应结构、统一错误码、Bean Validation、全局异常处理。
- Flyway 管理数据库迁移；操作日志与审计日志留存。
- 后端单元/集成/权限/并发测试可执行；前端 ESLint + 构建通过 + 关键 E2E。
